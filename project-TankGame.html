Overview

A top-down maze shooter built from scratch in Python with Pygame. You control a tank navigating a procedurally-rendered maze while an autonomous "attacker" hunts you down using real A* pathfinding — it recalculates a route to your position every couple of seconds, so it actually chases you through the maze rather than beelining through walls.

The problem

In the beging of high school joined an after school coding camp where I learned how to build games using python. This program is my final project, I decided to build a game like Pacman but with a ability to shoot. I didnt want the opponent to have a preprogrammed path, so I used the Pathfinder libery to give it live decision making.

What I built

The maze itself is generated from a small bitmap (1.png) — each pixel maps to a 25×25px tile, and black pixels become wall rects, so the level layout is literally paintable as an image. The player tank moves on WASD with rect-based collision against every wall tile, and firing spawns a bullet that travels toward the mouse cursor with real vector math.

The "attacker" enemy uses the pathfinding library's A* implementation over a grid built from the same maze data. Every 60 frames it recalculates a path from its current tile to the tank's tile, converts that path into a sequence of waypoints, and steers toward them one at a time — so it genuinely routes around walls rather than just moving in a straight line. When it gets within range of the tank it fires back, and bullets from both sides are checked against walls and against each other.
